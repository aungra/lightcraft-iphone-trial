iPhone 16 Pro・Safariでの試験用

LightCraftで写真を現像

まずはRICOH GR IIIxのDNGコピーを1枚、読み込んで試してください。

LightCraftを開く

写真と編集内容は、この端末のブラウザ内に保存されます。写真をこのサイトへアップロードする機能や、端末間の自動同期はありません。

原本は別に残し、作業後は File → Back Up Library… からバックアップしてください。サイトデータの削除などで、ブラウザ内の写真と編集内容が失われることがあります。

SafariでのRAW現像は検証中です。初回はWi-Fiで開き、通常のタブを1つ使ってください。

LightCraft v0.21.1の公式Web配布物をそのまま配信する、非公式の個人試験サイトです。開発元による運営・サポートを示すものではありません。
